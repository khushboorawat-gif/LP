# Timkolas store

Shopify build for the Timkolas gaming-console store.

- `shopify-theme/`: custom theme (upload to Shopify)
- `shopify-data/`: draft product import CSV (`tools/make_products_csv.py` regenerates it)
- `order-sheet/`: order mirror to Google Sheets (Worker + Apps Script + tests)
- `docs/`: research, setup and handover, tracking and SEO, experiment roadmap, draft page text

Start with `docs/shopify/01-setup-and-handover.md`. Nothing here has been run on a live Shopify store yet.
